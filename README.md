# СПОТ ЕАЭС — визитка (2 варианта)

Статический лендинг для услуг по официальному оформлению QR-кода по системе СПОТ.

## Версии

- **Главная (выбор):** https://elenasamanchuk.github.io/spot-eaeu/
- **Вариант 1 — Корпоративный:** `/v1/`
- **Вариант 2 — СПОТ24:** `/v2/`

На каждой странице есть переключатель версий вверху.

## Запуск локально

```bash
cd ~/Projects/spot-eaeu
python3 -m http.server 8080
```

Откройте http://localhost:8080

## Деплой

Автоматически через GitHub Actions при пуше в `main`.
